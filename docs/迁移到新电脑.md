# 迁移到新电脑（或换硬盘位置）

三种搬法，按"想带走多少"选。都要在目标机器上跑一次 `install.py`。

## 一、只搬程序：给别人一套干净的

```bash
python radar.py pack
```

产物 `dist/hermes-radar-<版本>-<日期>.zip` 只有几百 KB，里面是代码、模板、安装脚本。
对方解压后：

```bash
python install.py          # 装环境 + 回答几个问题
```

就有了一套空资料库的实例。这一步不会带上你的任何文章、图片或密钥。

## 二、程序和资料一起搬：换自己的电脑

1. 在老机器上 `python radar.py pack`，把所有东西打个包；
2. 额外拷贝 `data/` 整个目录（几十 G 的话直接用移动硬盘，别压缩）；
3. 新机器上解压程序包，把 `data/` 放到同一个位置；
4. `python install.py`。

`install.py` 看到已有 `data/radar.db` 不会覆盖，只补环境。

### data/ 里各是什么，能不能不拷

| 路径 | 内容 | 不拷的后果 |
|---|---|---|
| `data/radar.db` | 条目、评分、笔记、对话记录 | 资料库是空的，要重新抓 |
| `data/documents/` | 每篇文章的离线页面（原文删了也能看） | 阅读页打不开原文 |
| `data/blobs/` | 图片原图，按内容寻址存放 | 图看不全 |
| `data/papers/` | 下载的论文 PDF | 要重新下载 |
| `data/logs/` | 运行日志 | 无影响，可以不拷 |
| `data/backups/` | 历史数据库备份 | 无影响，可以不拷 |
| `data/exports/` | 导出的文件 | 无影响 |

### 必须重填的东西

- **API key / webhook / 微信数据库密钥**：`config/secrets.dpapi.json` 用 Windows DPAPI 加密，
  只对"原机器 + 原 Windows 账户"有效。拷过去解不开，程序会当成没配（不会崩），
  在 设置 页重填一次。
- **微信路径**：`config/startup.json` 里存着 `wechat_exe` 的绝对路径，新机器路径不同，
  要么删掉这个文件（就不自动拉起微信了），要么改路径。
- **端口**：`config/settings.json` 里的 `port` 如果在新机器上被占用，安装向导会提示换一个。

### 不用改的东西

代码里没有任何绝对路径。`Radar.exe` 与 `Start Radar.vbs` 都按自己的位置推算目录，整个文件夹挪到
`D:\apps\radar` 也能直接跑。配置里的路径只有 `startup.json` 一个例外，见上。

## 三、整个目录直接拷

最省事，但有三个坑：

1. `.venv/` 里有指向原路径的绝对路径，拷过去多半不能用了 —— 拷完删掉它，
   重新 `python install.py` 会重建。
2. `__pycache__/` 里的 .pyc 也是按原路径缓存的，删掉更干净。
3. `data/STOP_RADAR` 如果存在，新机器一启动就会立刻退出 —— 删掉这个文件。

## 迁移后自检

```bash
python radar.py where          # 目录、版本、数据库版本对不对
python radar.py check          # 语法检查
python install.py --dry-run    # 只检查不安装，确认清单齐全
```

启动后打开网页，随便点开一篇文章的"离线原文"，看图片能不能显示 —— 图片走
`data/blobs`，是最容易漏拷的部分。

## 常见问题

**双击 Radar.exe 没反应**
它是窗口版程序，没有控制台可看。先跑 `Radar.exe status` 看服务在不在；再看看
`data/logs/tray.log`（托盘里的异常只会写这里）。要看清错误就用
`.venv\Scripts\python.exe radar_tray.pyw` 前台跑一次。最常见的原因还是没跑过
`install.py`，或者 `.venv` 是从别的机器拷过来的、路径失效。

**网页能开但一直不出新文章**
看 `data/logs/app-worker-console.log` 最后几十行。多数是订阅源为空，或者
`config/settings.json` 里的 `llm.enabled` 是 false（那就只抓取、不精读）。

**密钥项显示"需重填"**
就是上面说的 DPAPI 跨机器失效。设置页重填即可，旧密文会被覆盖。

**端口被占用**
`python install.py --reconfigure` 换端口，或者改 `config/settings.json` 里的 `port`，
然后重启。
